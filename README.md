# 🤖 TradeMaster AI TJ Bot

AI-обучающий трейдинг-бот для Telegram (Таджикистан) с бесплатным ИИ Groq в реальном времени.

> ⚠️ **Важно:** этот бот — образовательная платформа. Все AI-ответы явно помечены как обучающий материал,
> а не финансовая рекомендация. Перед запуском в продакшн проконсультируйтесь с юристом относительно
> требований местного законодательства к образовательным/финтех-продуктам и платёжным интеграциям.

## 🔑 Получение бесплатного Groq API ключа

1. Зайдите на [console.groq.com](https://console.groq.com)
2. Зарегистрируйтесь (можно через Google-аккаунт)
3. Перейдите в раздел **API Keys** → **Create API Key**
4. Скопируйте ключ и вставьте в `.env` как `GROQ_API_KEY`

Бесплатный тариф: ~30 запросов/мин, 14400 запросов/день на модели Llama 3.3 70B — этого достаточно
для старта проекта с несколькими сотнями активных пользователей.

## 🔑 Настройка резервных AI-провайдеров (опционально, но рекомендуется)

| Провайдер | Где получить ключ | Бесплатный лимит |
|---|---|---|
| OpenRouter | https://openrouter.ai/keys | Несколько бесплатных моделей Llama/Mistral |
| Google Gemini | https://aistudio.google.com/app/apikey | 15 запросов/мин (Gemini 1.5 Flash) |
| Together.ai | https://api.together.ai/settings/api-keys | Бесплатные кредиты при регистрации |
| Cohere (эмбеддинги для RAG) | https://dashboard.cohere.com/api-keys | 1000 запросов/мес бесплатно |

Заполните соответствующие переменные в `.env` — бот автоматически переключится на резервный
провайдер, если у Groq закончится лимит.

## 🚀 Запуск проекта

### Вариант 1: Docker (рекомендуется)

```bash
cp .env.example .env
# отредактируйте .env — впишите минимум BOT_TOKEN и GROQ_API_KEY
docker-compose up -d --build
docker-compose logs -f bot
```

### Вариант 2: Локально (Node.js 20+)

```bash
# 1. Установите MongoDB и Redis локально, либо укажите внешние в .env
cp .env.example .env

# 2. Установите зависимости
npm install

# 3. Запустите бота
npm start
# или в режиме разработки с авто-перезапуском:
npm run dev

# 4. (Отдельно) запустите админ-панель
npm run admin
```

## 🧠 Как добавить учебные материалы в базу знаний (RAG)

1. Откройте админ-панель → раздел **База знаний** (`/admin/ai-knowledge`)
2. Загрузите документ (PDF, DOCX, TXT, MD) с учебным материалом
3. Система автоматически разобьёт документ на фрагменты и векторизует их через Cohere
4. После этого AI-наставник будет использовать эти материалы для ответов с указанием источника

Программно (пока без UI) добавить материал можно так:

```js
import { addKnowledgeDocument } from './src/services/ragService.js';

await addKnowledgeDocument({
  title: 'Основы риск-менеджмента',
  text: 'Полный текст урока...',
  sourceType: 'lesson',
  language: 'ru',
});
```

## ⚖️ Дисклеймер

Бот не предоставляет индивидуальных финансовых рекомендаций и не гарантирует доходность. Все
AI-ответы по рынку сопровождаются пометкой об образовательном характере контента и риске потери
средств. Перед запуском платёжных интеграций (Alif, Eskhata, Humo) уточните актуальные требования
провайдеров — их публичные API могут потребовать отдельного юридического договора с оператором.
